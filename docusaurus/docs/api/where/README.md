# Overview

## Description

This category provides a set of extensions for `WHERE ... IN` conditions on `SelectQueryBuilder`, `UpdateQueryBuilder` and `DeleteQueryBuilder`.

### Methods
- [whereIsIn](./whereIsIn): add `IN` / `NOT IN` conditions by column name.

For a typesafe version that takes the column from an entity property, see [whereIsInTyped](../typed/whereIsInTyped).
